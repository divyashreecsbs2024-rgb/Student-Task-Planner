# Student Task Planner

A simple and user-friendly Student Task Planner web application built using React and Vite.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Display task date
- Display task priority
- Simple and clean user interface

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite
